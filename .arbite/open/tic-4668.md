## Description
Open an xdg-desktop-portal ScreenCast session covering all three monitors, read the PipeWire stream(s) (GStreamer pipewiresrc is installed), and keep the latest frame per monitor as a grayscale luminance array placed in global coordinates. Persist the portal restore token so the permission dialog appears once and later runs reconnect silently. Capture at 15 to 30 fps; the cursor itself should not be drawn into the frames.

Put it behind an adapter exposing: start, stop, and patch(x, y, size) returning the luminance square around a global point, handling monitor edges and the gaps in the layout (DP-5 starts at y=265).

Done when: a test program saves a patch around a given global point from each monitor and it matches what is on screen, a second run asks for no permission, and stop really stops the stream.
